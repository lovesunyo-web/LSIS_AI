# 3D 박피 케이블 뷰 수정본

## 이번 요청 반영
1. 도체 노출 길이를 줄였습니다.
2. 절연과 시스 사이의 흰부분/개재/연합부는 측면 탈피 길이를 0으로 처리했습니다.
   - 측면 원통으로 길게 보이지 않고, 단면 디스크에서만 보입니다.
3. 최외층 시스 구간을 더 길게 조정했습니다.
4. 2D 단면도에서 실제 적용된 구성품만 3D로 전달합니다.
   - 미적용 구성품은 3D에서도 생성하지 않습니다.
5. `단면도 설명` 체크 시 3D 위에는 빨간 동그라미 숫자만 표시합니다.

## Three.js 적용
ZIP 안의 `lib/three.min.js`는 자리표시자입니다.
실제 3D 표시 전 공식 Three.js r128 파일 내용으로 덮어써 주세요.

공식 주소:
https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js

## 실행 권장
로컬 파일 더블클릭보다 `START_LOCAL_SERVER.bat` 실행 후 표시되는 주소로 접속하는 것을 권장합니다.


## 추가 반영
- 2D/3D 분할 비율을 3:7로 조정했습니다.
- 3D 케이블 외경 표현을 약 1.2배 확대하고, 카메라 맞춤을 보정해 화면 밖으로 나가지 않도록 했습니다.
- 절연체와 시스 사이의 X축 이격을 제거했습니다.
- 3D 번호는 2D 단면도 설명 번호와 동일한 번호를 사용하며, 동일 구성품은 반복 번호를 표시하지 않습니다.
