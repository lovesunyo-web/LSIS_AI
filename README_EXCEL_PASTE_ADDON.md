# 엑셀 붙여넣기 추가 기능

## 버튼
- 양식보기: 포함된 엑셀 양식을 다운로드합니다.
- 붙여넣기: 엑셀에서 복사한 표를 붙여넣어 메인화면 좌측 선택값에 반영합니다.
- 파일방식/파일제출 버튼은 제거했습니다.

## 사용법
1. 양식보기로 엑셀 양식을 엽니다.
2. 입력 시트에서 값을 작성합니다.
3. 보이는 표(No./항목/입력 방식/설명/입력값/입력상태)를 복사합니다.
4. 프로그램에서 붙여넣기 버튼을 누르고 Ctrl+V 후 반영합니다.
5. 입력상태가 `입력`인 행만 반영됩니다.

## 수정 범위
- 기존 계산/도면 로직은 수정하지 않았습니다.
- `excel-paste-addon.js`를 추가하고 `index.html`에 스크립트 연결을 추가했습니다.
